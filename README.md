# Resonance Chat

ゲーム内チャットをリアルタイムで見やすく表示する、Windows 向けのオーバーレイツールです。  
WinDivert を使ってパケットを受信し、ゲームのチャット内容を再構成してウィンドウ上に表示します。

## 主な機能

- ワールド、チャンネル、パーティ、ギルドチャットの表示
- チャットチャンネルごとの色分け
- キーワード通知音
- チャット読み上げ (TTS)
- ブラックリスト機能
- テーマ、文字サイズ、透明度などの見た目調整
- 常に最前面での表示

## 動作環境

- OS: Windows 10 / Windows 11 (64bit)
- 権限: 管理者権限が必要
- その他: Microsoft Edge WebView2 ランタイム

WebView2 が入っていない環境では、初回起動時に Microsoft からインストーラが案内される場合があります。

## インストール

1. [Releases](../../releases) から配布ファイルをダウンロードします。
2. ポータブル版を使う場合は ZIP を展開します。
3. インストーラ版を使う場合はセットアップを実行します。
4. 未署名リリースでは Windows の `Unknown publisher` や SmartScreen 警告が出ることがあります。

## アップデート時の注意

- 旧バージョンから更新するときは、先に `resonance-chat` を終了してください。
- `WinDivert64.sys` を更新できないエラーが出た場合は、Windows を再起動してから再試行してください。
- それでも更新できない場合は、ポータブル版 ZIP の利用をおすすめします。

## 使い方

1. 管理者権限でアプリを起動します。
2. ゲームを起動してログインします。
3. 対応するチャットが流れると、オーバーレイに表示されます。
4. 設定パネルからテーマ、通知音、TTS、ブラックリストなどを調整できます。

## セキュリティについて

- このツールは WinDivert を `sniff` / `recv_only` モードで使い、受信したパケットを読み取ります。
- パケットの送信や改ざんは行わない実装です。
- WebView2 が未導入の環境では、初回セットアップ時に Microsoft 由来のダウンロードが発生する場合があります。
- WinDivert を利用するため、管理者権限が必要です。

## 配布前チェック

- `WinDivert.dll` / `WinDivert64.sys` / 配布用 EXE / インストーラの SHA-256 を公開する
- WinDivert の照合結果を添付する
- Windows Defender などで配布物をスキャンする
- クリーンな git ワークツリーからビルドする

## 未署名リリースについて

- このプロジェクトは趣味開発を前提としており、コード署名なしで配布する場合があります。
- 未署名のため、Windows では `Unknown publisher` や SmartScreen の警告が出ることがあります。
- 気になる場合は、同梱のハッシュ値や WinDivert 照合レポートを確認してください。

## 開発

- フロントエンド: SvelteKit
- デスクトップアプリ: Tauri
- パケット処理: Rust + WinDivert

# Resonance Chat

ゲームのチャットをリアルタイムで表示するオーバーレイツールです。
パケットキャプチャによりゲーム内チャットを取得し、コンパクトなウィンドウに表示します。

## 機能

- ワールド / チャンネル / パーティ / ギルド チャットのリアルタイム表示
- チャンネルごとのタブ切り替え
- キーワード通知音
- チャット読み上げ (TTS)
- ブラックリスト（名前完全一致で非表示）
- テーマ切り替え・透明度・フォントサイズ調整
- 常に最前面に表示

## 動作環境

- **OS**: Windows 10 / Windows 11 (64bit)
- **権限**: **管理者権限が必要です**（パケットキャプチャのため）
- **その他**: Microsoft Edge WebView2（未インストールの場合、初回起動時に自動インストールされます）

## インストール

1. [Releases](../../releases) から `resonance-chat_x.x.x_x64-setup.exe` をダウンロード
2. ダブルクリックして実行
3. Windows Defender などのセキュリティ警告が出た場合は「詳細情報」→「実行」を選択
   ※ WinDivert（パケットキャプチャドライバ）を使用しているため警告が出ることがあります

## 使い方

1. **管理者として実行**（右クリック→「管理者として実行」）
2. ゲームを起動してログインする
3. ログイン後、チャットが自動的に表示され始めます

## ブラックリスト

チャット画面でプレイヤー名をクリック → 「🚫 ブロック」で非表示にできます。
解除は設定パネル（右上の歯車アイコン）→「ブラックリスト」セクションから。

## セキュリティについて

- このツールはパケットを**読み取るだけ**で、送信・改ざんは一切行いません
- ユーザーデータはすべてローカルに保存され、外部サーバーへの送信はありません
- WinDivert ドライバを使用しているため、一部のウイルス対策ソフトが反応する場合があります
